Fonctionnalités

Ce que fait le dashboard en un coup d'œil.

🗺️
Cartes interactives
Visualisation Folium et Pydeck avec choroplèthes, marqueurs et couches dynamiques par indicateur.
📊
Tableaux de bord
KPIs en temps réel : population, chômage, valeur foncière, densité d'entreprises par commune.
⚡
Score de risque
Indicateur composite vert / orange / rouge calculé pour chaque commune à partir de multiples critères socio-économiques.
🤖
Assistant IA
Chatbot intégré (Mistral ou Groq) pour interroger les données en langage naturel et obtenir des analyses territoriales.
🏠
Immobilier
Prix au m², valeurs foncières moyennes et nombre de transactions par commune.
🔍
Comparatif communes
Sélection et comparaison multi-communes sur tous les indicateurs disponibles.
// Démarrage rapide

Installation locale

Lancer le projet en local en quelques commandes.

terminal
$ git clone https://github.com/sonia-ice/app-streamlit
$ cd app-streamlit
$ pip install -r requirements.txt
$ streamlit run app.py

Prêt à explorer les données ?

L'application est déployée et accessible directement en ligne.
